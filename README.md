# execution-evaluation

Interactive companion page (Chinese) for the paper 《执行与评估：人工智能对中国就业、增长与收入分配的影响》 by 甘犁 and 尹志超. The page solves the paper's model in the browser: readers can vary the uncertain parameters and policies and compare the results with the paper's baseline calibration. It is one self-contained HTML file; open `index.html`.

论文《执行与评估：人工智能对中国就业、增长与收入分配的影响》（甘犁、尹志超）的中文交互式附录。页面在浏览器中实时求解论文的模型，读者可以改变不确定的参数和政策，并与论文的基准校准比较。页面是一个独立的 HTML 文件，从 `index.html` 打开。
